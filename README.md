# Antigravity Exam Platform

A professional full-stack platform for creating and conducting exams.

## 🚀 Getting Started

### 📂 Structure
- `backend/`: Node.js + Express + SQLite
- `frontend/`: React + Vite + Tailwind CSS

### 🛠️ Installation

1.  **Backend Setup**:
    ```powershell
    cd backend
    npm install
    npm start
    ```

2.  **Frontend Setup**:
    ```powershell
    cd frontend
    npm install
    npm run dev
    ```

## 🔑 Default Credentials
- **Admin**: `admin@example.com` / `admin123`
- **Student**: Register a new account via the Signup page.

## ✨ Features
- **Role-Based Auth**: Secure Admin and Student portals.
- **Exam Management**: Create exams with MCQ, Short Answer, and Coding questions.
- **Real-time Exam**: Interactive attempt interface with a countdown timer.
- **Leaderboard**: Instant rankings based on performance.
- **Glassmorphism UI**: Modern, premium design system.
